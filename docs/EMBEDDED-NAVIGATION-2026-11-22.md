# 1.11.1 探索子卡中的版本导航

日期：2026-11-22。配套 `dsh-btw-explore 0.3.4`；实际宿主为安装版 DSH `0.2.2-rc.5`。

## 问题与行为

以前工具栏保存原生子卡中的回答后，调用主工作区导航打开新会话；探索卡片仍绑定旧会话。旧会话被版本聚焦流程归档后，重开原卡的续问还可能在模型调用前被宿主 blocked。

本版本为嵌入对话提供显式导航认领。探索插件保存卡片的新版本绑定并挂载目标原生输入框，工具栏随后完成版本聚焦。保存、回答切换和重生成可以留在原子卡内，来源摘录继续用于后续请求。

## 协议与竞态

工具栏派发 window CustomEvent `dsh-message-toolbar:open-version`，detail 含 `version: 1`、`sourceSessionId`、`targetSessionId` 和 `claim(handler)`。只有派发期间的第一个同步认领有效；handler 是零参数异步函数，完成代表目标已持久化并可交互。

没有认领者时沿用主工作区导航。认领后等待 handler；失败直接反馈当前操作，不再转到主窗口。认领处理未完成时，后续上下文操作在 mutation 前被拒绝，避免两次编辑交错切换。

输入框按挂载实例记录，导航前检查是否仍连接、是否被 `inert` 或 `aria-hidden` 覆盖。同 session ID 关闭重开也不会接收旧实例的迟到结果。被覆盖的目标不发送 focus；返回后可用现有重试入口完成。原生组件准备完成前，探索插件也检查当前可交互状态，防止隐藏输入框先触发归档。

若认领 handler 永不结束，该次操作保持 busy；关闭探索卡会通过卸载清理拒绝 handler 并恢复。外层 15 秒导航超时本身不会取消 handler。

## 验证

`npm test` 在合入远端最新的版本模型显示修复后运行，退出 0。host 7/7 和既有客户端检查通过；Node suite **190 项中 189 项通过、1 项因 Windows 文件符号链接权限跳过**。新增 13 项嵌入导航回归覆盖认领、失败、关闭、覆盖、同 ID 重挂、连续操作、延迟聚焦和恢复。

`npm pack` 产生 `dsh-message-toolbar-1.11.1.tgz`。与探索插件 `0.3.4` 的归档一起，通过 DSH 插件命令安装到临时 profile，22 个真实宿主检查点通过，包含重生成首次请求及进程重启恢复。浏览器实际完成编辑保存、切旧/新版本、关闭重开和原生续问，主窗口保留原会话；provider 请求包含编辑后的回答和原始引用。

主聊天原有 16 条事件逐条一致；首次原生恢复仅新增宿主 `session/end-seed` 生命周期标记，没有新增主聊天问答或模型步骤。最终文档补充后重新打包，并核对生产文件与实测归档一致。

本轮使用临时 profile 与本地脚本模型，未修改用户桌面 profile、安装文件或真实模型配置，未重启桌面实例。临时服务已停止。`git diff --check` 通过。
